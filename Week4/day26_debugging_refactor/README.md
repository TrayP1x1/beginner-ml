# Day 26 - Debugging and Refactoring

Take a working script and improve it without changing the result.

## Tasks

- Rename unclear variables.
- Break one long function into two or three smaller functions.
- Add two strategic print statements for debugging.
- Remove duplicated code.
- Write a short note about what became easier to read.

## Why This Matters

Real programming is not only writing new code.
A lot of the job is making existing code clearer, safer, and easier to debug.
