# Bonus Conic Plotting

This bonus exercise is optional enrichment.
It is less important for your upcoming test than CSV work, modeling, and visualization.

## Goal

Practice:

- mathematical thinking
- plotting curves
- writing helper functions

## Tasks

1. Write a function that creates `x` values with NumPy.
2. Compute `y` values for a curve such as a parabola.
3. Plot the curve with matplotlib.
4. Change parameters and observe how the shape changes.
5. Write a short summary of what each parameter changes visually.

## Why It Helps

This is not required for the test, but it strengthens your plotting and equation intuition.
