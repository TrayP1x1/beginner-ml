# Day 21 - Capstone

Build one independent mini-project and explain every step in plain English.

## Tasks

- Choose regression or classification.
- Use at least one cleaning step and two plots.
- Train one model and report one metric.
- Write a short conclusion about what worked and what you would improve next.
- Strong recommended choices: housing for regression, Titanic for classification.
- Structure the project with reusable helpers or modules if the file gets large.
- Add a small config object, constants section, or clear parameter block.
- Include one section called "tradeoffs" where you explain what you simplified and why.

## Stronger Python Goal

This project should prove that you can combine data work with readable Python structure.

## Suggested Output Files

- one `.py` file or notebook scratch file created from your IDE
- optional `.png` plots for visualization days
- a short text summary in comments or markdown

## Data

- Week 1 mainly uses `data/tiny_scores.csv`
- Week 2 and Week 3 mainly use `data/student_dev_ai_practice.csv`

- Best capstone classification dataset: `data/kaggle/titanic.csv`
- Bonus capstone: `data/kaggle/iris.csv`

Push the final result to GitHub. This becomes your personal proof that you can do the full workflow on your own.
