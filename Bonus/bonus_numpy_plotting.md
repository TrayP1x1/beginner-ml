# Bonus NumPy Plotting

This bonus exercise is inspired by the array and plotting ideas from your earlier geometry homework.

## Goal

Get more comfortable with:

- NumPy arrays
- 2D points
- plotting coordinates with matplotlib
- simple transformations like translation

## Tasks

1. Create a NumPy array of 2D points such as:

```python
points = np.array([
    [0, 0],
    [1, 2],
    [2, 1],
    [3, 3],
])
```

2. Plot the points with matplotlib.
3. Write a function `translate_points(points, dx, dy)` that shifts all points.
4. Plot the original points and the translated points on the same figure.
5. Write 2 sentences explaining what changed.

## Why It Helps

This improves your comfort with:

- array shapes
- indexing columns like `points[:, 0]`
- plotting arrays directly
