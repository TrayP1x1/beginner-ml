## Task Levels

### Level 1 - Easy

- Load, inspect, and clean the file.
- Create at least two visualizations.
- Create at least one engineered feature.

### Level 2 - Core

- Write a short markdown or text summary of what you learned from the data.
- Split your code into helpers such as `load_data()`, `clean_data()`, `make_plots()`, and `write_summary()`.
- Use `main()` and keep top-level code minimal.

### Level 3 - Hard

- Add type hints and at least one validation check.
- Save a clean feature matrix and target column that you could reuse for model training.
- Run the same workflow on one Kaggle dataset and note what becomes harder.

## Stronger Python Goal
