# Data Folder

This folder contains the CSV files used by the bootcamp.

- `tiny_scores.csv`: very small file for learning basic CSV reading and simple summaries
- `student_dev_ai_practice.csv`: the main structured practice dataset for exploration, plotting, preprocessing, regression, and binary classification
- `kaggle/housing_prices.csv`: more realistic regression practice
- `kaggle/titanic.csv`: more realistic binary classification practice
- `kaggle/iris.csv`: bonus multiclass classification practice

Recommended use:

- Week 1: use `tiny_scores.csv`
- Week 2: use `student_dev_ai_practice.csv` for pandas, cleaning, and plotting
- Week 3: use `student_dev_ai_practice.csv` for end-to-end ML pipeline practice
- Week 4: reuse `student_dev_ai_practice.csv` or move to Kaggle datasets for engineering-style projects

Best progression:

1. Learn basic Python file and CSV workflow with `tiny_scores.csv`
2. Practice structured data work with `student_dev_ai_practice.csv`
3. Build an ML pipeline on `student_dev_ai_practice.csv`
4. Move to `kaggle/housing_prices.csv` for regression
5. Move to `kaggle/titanic.csv` for classification
6. Try `kaggle/iris.csv` only after the first five feel manageable
