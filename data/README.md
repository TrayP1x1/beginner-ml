# Data Folder

This folder contains the CSV files used by the 21-day bootcamp.

- `tiny_scores.csv`: very small file for learning basic CSV reading
- `student_dev_ai_practice.csv`: tabular practice data for exploration, visualization, regression, and binary classification
- `kaggle/housing_prices.csv`: realistic regression practice
- `kaggle/titanic.csv`: realistic binary classification practice
- `kaggle/iris.csv`: bonus multiclass classification practice

Recommended use:

- Week 1: use `tiny_scores.csv`
- Week 2: use `student_dev_ai_practice.csv` for pandas and plotting
- Week 3: use `student_dev_ai_practice.csv` for PyTorch training
- After the basics feel comfortable, start using the Kaggle datasets for mock tests and capstones

Best progression:

1. Learn the workflow with `tiny_scores.csv`
2. Practice the full pipeline with `student_dev_ai_practice.csv`
3. Move to `kaggle/housing_prices.csv` for regression
4. Move to `kaggle/titanic.csv` for classification
5. Try `kaggle/iris.csv` only after the first four feel manageable
