# Week1

Use one day folder at a time and code the solutions from your IDE.

- Day 1: variables, types, conversion, and Pythonic naming
- Day 2: loops, lists, indexing, and defensive iteration
- Day 3: functions, return values, defaults, and docstrings
- Day 4: CSV basics with parsing helpers and validation
- Day 5: useful modules and file-path handling
- Day 6: NumPy basics with shape awareness and reusable array helpers
- Day 7: mini project, dataclass-style thinking, and `main()` project structure

Suggested workflow:

1. Read the matching notebook section.
2. Open the day folder for the exercise brief.
3. Write your solution in your IDE.
4. Add type hints and at least one helper function whenever possible.
5. Commit your progress with git.
6. If the exercise needs libraries, run the notebook or training code in Colab.

Week 1 is still beginner-friendly, but the standard is higher now.
By the end of the week, you should be able to:

- write readable variable names and avoid throwaway top-level code
- break work into helper functions with type hints
- use lists, loops, and conditionals without hidden logic bugs
- validate simple inputs before using them
- build a small script with imports at the top, helpers in the middle, and `main()` at the bottom
