# Day 1 - Variables and Types

Write `intro_variables.py` in your IDE and practice creating values, printing them, and converting between string, int, and float.

## Tasks

- Create variables for your name, age, study hours today, and whether you want the role.
- Print each variable and also print its type.
- Convert the string `"42"` to both `int` and `float`.
- Write 3 lines explaining when to use `int`, `float`, and `str`.

## Suggested Output Files

- one `.py` file or notebook scratch file created from your IDE
- optional `.png` plots for visualization days
- a short text summary in comments or markdown

## Data

- Week 1 mainly uses `data/tiny_scores.csv`
- Week 2 and Week 3 mainly use `data/student_dev_ai_practice.csv`
