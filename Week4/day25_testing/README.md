# Day 25 - Writing Tests With `unittest`

Write basic tests for your helper functions.

## Tasks

- Create a `tests` folder.
- Write one test for a data-preparation function.
- Write one test for a model helper function.
- Run the tests with:

```bash
python -m unittest discover
```

## Good Test Targets

- a function that infers regression vs classification
- a function that fills missing values
- a function that computes a summary number

## Why This Matters

Tests help you change code without guessing whether you broke something.
Even 2 or 3 simple tests can make your project look far more disciplined.
