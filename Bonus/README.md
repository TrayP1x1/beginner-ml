# Bonus Practice

This folder keeps optional extra exercises inside the bootcamp pack so the project stays self-contained.

These are inspired by earlier homework-style ideas, but rewritten here as standalone practice.

- `bonus_numpy_plotting.md`: arrays, points, plotting, simple transformations
- `bonus_least_squares_regression.md`: one-feature regression and pseudoinverse ideas
- `bonus_conic_plotting.md`: optional math and plotting enrichment

These are optional.
Do them after the main Weeks 1 to 3 path or after Week 4, not before.
