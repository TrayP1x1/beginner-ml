# Bonus Least-Squares Regression

This bonus exercise is inspired by the regression ideas from your earlier homework and is directly useful for the housing dataset.

## Goal

Understand a very simple regression pipeline before using bigger PyTorch models.

## Tasks

1. Load `data/kaggle/housing_prices.csv` with pandas.
2. Choose one feature first, for example `area`.
3. Predict `price` using only that one feature.
4. Plot the scatter plot of `area` vs `price`.
5. Fit a simple line using a regression method you understand.
6. Plot the predicted line on top of the scatter plot.
7. Report at least one metric such as RMSE or R2.

## Stretch Version

After the one-feature version works:

1. Use multiple numeric features.
2. Compare single-feature vs multi-feature performance.
3. Write 3 sentences about multicollinearity and why housing data can be tricky.

## Why It Helps

This is one of the best bridges between beginner pandas work and real regression modeling.
